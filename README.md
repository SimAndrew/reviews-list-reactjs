## Reviews List

### About:
The reviews list is a slider with people's feedback.

Features:
- Clicking on Surprise me, will display a random review.

You can try here: [reviews-list-reactjs.netlify.app](https://reviews-list-reactjs.netlify.app/)

### Run the app:

- Clone a project: `git clone`

```
git clone https://github.com/SimAndrew/reviews-list-reactjs.git
```

- Open project code in your editor.
- Install the dependencies, enter into the terminal:

```
npm install
```

- Run the project, enter into the terminal:

```
npm run dev
```
